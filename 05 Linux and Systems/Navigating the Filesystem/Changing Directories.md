To navigate the filesystem, use `cd`.

There is a directory called `Documents` located in the [[Tilde Home Directory]] of the sysadmin user. To move from home to the `Documents`, use the directory name as the argument to the `cd` command.

<!-- embed removed: Pasted image 20230617153113.png (file not in vault) -->
<!-- embed removed: Pasted image 20230617153124.png (file not in vault) -->

When used with no arguments, `cd` will take the user to their home directory.
