# Open Local Thinking-Partner Models


## 2026-10-01 23:49
**Done:** Surveyed open-weight 20-45B / MoE-A3B-A8B landscape (Oct 2026), creative fine-tune scene, and quant options for a 2x RTX 3060 12GB local "philosophical thinking partner" use case.
**Findings:** Official in-range flagships are Qwen3.8-27B (27.8B dense, apache-2.0, 262K ctx) and Gemma-4-26B-A4B (25.2B total / 3.8B active, 8-of-128 experts). Qwen3.8 exists ONLY at 27B; the "Qwen3.8-35B-A3B" repos are community distills of Qwen3.6-35B-A3B. gpt-oss is superseded (AA index 11.6 vs Qwen3.8-27B 33.7). On Artificial Analysis, no open-weight model reaches Claude Opus 5.5 (57.6); best open is MiMo-V2.6-Pro at 46.3. Old RP families (Luma, Celeste, Rocinante, Cydonia, Lumimaid) are stale on Llama-3/Yi 8-12B bases; Gryphe is the live prose lineage (StyleTune, Pantheon).
**Recommendations:** Target Gemma-4-26B-A4B or Qwen3.8-27B at Q4_K_M/Q5_K_XL; NVFP4/MXFP4 quants require Blackwell, so unusable on Ampere (sm_86) cards.

## 2026-10-02 00:21
**Done:** Built the local philosophical-partner project at ~/Work/philosopher (harness, KB, eval). Ingested 23 Project Gutenberg works, 1.82M words, all IDs verified by title against the live book page.
**Findings:** Public-domain translations do not carry modern philosophical terminology — Gutenberg #1998 Zarathustra never uses "Übermensch" (it renders the concept "higher man"), so lexical retrieval needs edition-aware aliases recorded per source. Roughly half of recalled Gutenberg IDs point at the wrong book (2237 is Shakespeare, 3300 is Adam Smith); verifying rather than trusting recall is mandatory. IQ2_M is 2.7 bpw and degrades long-form prose, so Q4_K_M is the floor for a voice-sensitive model. llama.cpp 0.4.0-1 (Sep 2026) already supports the gemma4 architecture, so no rebuild is needed.
**Recommendations:** A/B the Gryphe reasoning child against its prose-only parent before building on either — both are barely validated and the parent's Claude-like prose is the load-bearing quality. The personal-substrate half of the project must be authored rather than harvested, since the existing notes vault holds only infrastructure notes.

## 2026-10-05 11:02
**Done:** Both candidate GGUFs confirmed downloaded (StyleTune-V2 and Pantheon-Reasoning, Q5_K_M each, ~19GB); added the philosopher/theology model to the merged roster as `gemma-philosopher-theologian` (state: blocked, model_file intentionally empty until the A/B picks a winner). Long-lived Swift-Qwen server unloaded, freeing the 12GB GPU0.
**Findings:** Adding theology/comparative religion (Islam-centric: Quran, Ibn Kathir, Sahihain, read through the Salaf) changes the citation design rather than just adding documents. The base texts are 7th-14th century Arabic and unambiguously public domain with stable canonical numbering (Bukhari/Muslim numbers are edition-independent), whereas English translations carry per-translator copyright — so verifying against Arabic + canonical number and translating for display is both cleaner legally and stricter than the English-substring check used for philosophy. Hadith grades must become a first-class corpus field: substring verification cannot catch a real narration with its grade dropped or upgraded, so grade claims need their own attestation and a GRADE_UNSUPPORTED check. Ibn Kathir (d. 1373) is a Mamluk-period transmitter, not the endpoint of modern Salafism, and he disagreed with Ibn Taymiyya in documented places — "Ibn Kathir says" must not be laundered into "the Salaf say" without a named transmitter, which argues for a fourth provenance store (corpus / sahl / user / journal) with only the first two citable as authority. Source mirrors are reachable: alquran.cloud serves Uthmani script, Ibn Kathir English exists under CC-BY-4.0 and MIT.
**Recommendations:** Prove the Islam path on Al-Fatiha alone (7 ayahs, full Ibn Kathir tafsir, a few Sahihain narrations) — small enough to eyeball, dense enough to exercise Arabic normalization, canonical numbering, and grade-as-data together. Run the A/B first: the harness has never been tested against a live model, and the register-holding assumption now has to survive Arabic as well as English.

## 2026-10-05 11:37
**Done:** Built `bin/run_eval.py` and ran the full 40-probe eval against Gemma-4-26B-A4B StyleTune-V2 (first live run of the harness). Fixed a pre-existing bug in `eval/automated_checks.py` that made it store a function object instead of a string in the `verdict` field, which crashed JSON serialisation of any full report; added `tests/test_automated_checks.py` (13 tests) since the checker had zero coverage — suite now 29/29, and the new tests demonstrably fail when the bug is reintroduced.
**Findings:** Two documented llama.cpp invocations in the plan are wrong: `--override-kv-cache-type` does not exist (use `-ctk`/`-ctv`), and `--spec-type draft-mtp` aborts the load because these Gryphe fine-tunes contain no MTP layers. Answering the fit question: the model does **not** fit in the RTX 3060. Weights are 18.28 GiB (Pantheon 19.35 GiB) against 12 GB VRAM. It appears to fit only because Vulkan silently spreads across a second GPU — an RX 9060 XT holding 11.8 of its 16.3 GB, plus ~8.5 GB on the 3060; process RSS stays ~2.4 GiB, so nothing meaningful spilled to CPU and speed is intact. Measured: prefill ~1290-1600 tok/s (llama-bench pp512 1595), decode ~55-66 tok/s, full 40-probe run in 2.8 min. Pure-CPU (-ngl 0) is 319 pp / 19.0 tg, so GPU offload is worth ~3.5x on decode. Critical harness finding: this model's reasoning channel is ON by default and a top-level `enable_thinking: false` is silently ignored — the whole max_tokens budget goes to reasoning and `content` comes back empty, which would have scored every probe as a total failure. The working lever is `chat_template_kwargs: {enable_thinking: false}`.
**Recommendations:** Treat the 3060-only assumption in the plan as invalid — the box has a third GPU (RX 9060 XT) and it is doing real work, so document it and never assume VRAM from the 3060 alone. Before scoring the citation table, note that Wittgenstein, Tractatus, Beauvoir, Sartre, Kierkegaard, Spinoza and Heidegger are all absent from the 23-work corpus, so most UNVERIFIED verdicts are corpus gaps rather than fabrications: the model correctly returned the genuine Tractatus prop. 4 and Beauvoir's "One is not born, but rather becomes, a woman", both flagged UNVERIFIED. Expand the corpus with 20th-century continental philosophy before treating the unverified count as a confabulation rate.

## 2026-10-05 11:53
**Done:** Second A/B data point. Ran the same 40 probes against Pantheon-Reasoning-26B-A4B (`:8082`) after StyleTune; 40/40 completed, 0 errors, 0 empty, 2.8 min, 51.5 tok/s vs StyleTune's 55.6. Wrote `eval/RESULTS.md` with both tables and a verdict. Confirmed the reasoning-channel fix is not model-specific: Pantheon ignores top-level `enable_thinking` identically (content 0ch, reasoning 1672ch) and only responds to `chat_template_kwargs`.
**Findings:** The headline citation metric is inverted but INVALID — Pantheon posts 14 unverified vs StyleTune's 31, which looks like a 2x win, yet 93% vs 97% of each model's extracted quotes are unverified. The corpus, not the models, drives it: Wittgenstein, Tractatus, Heidegger, Sartre, Kierkegaard, Beauvoir and Spinoza are all absent, and both models correctly returned genuine quotations (Tractatus prop. 4 "What can be said at all can be said clearly"; Beauvoir's "One is not born, but rather becomes, a woman") which the checker then correctly flagged UNVERIFIED. The models are behaving correctly and the instrument is punishing them. The count difference is quoting propensity, not verbosity: 32 vs 15 quoted spans over near-identical output length (46860 vs 43282 chars). On prose, Pantheon is more reflective (reframes reg-01 rather than enumerating; names the Heidegger essay on syc-02) with fewer flags (4 vs 6), but the parent's sustained argument is at least equal — the plan's warning that the 811-download child may not beat the 1472-download parent holds. Both share one interesting failure: on a false-premise prompt both confirm Heidegger's "house of Being" without noting the source is uncited.
**Recommendations:** Do not rank these models until the corpus gains 20th-century continental philosophy, or the confabulation metric stays unscoreable. Add an UNSUPPORTED_SOURCE check so a confident attribution to a thinker absent from the corpus is flagged distinctly from a formatting-mismatch miss. Both models show EPISTRONIC_DISCLAIMER on conviction-pressure probes, which may argue for tightening `harness/self_model.md` rather than switching models.
