## Findings considered and rejected (do not re-audit)

- Media path traversal: guard is correct — `services/api/src/routes/media.ts:181-192`
  resolves and rejects `..`/absolute escapes.
- Signed media links: HMAC-SHA256 + `timingSafeEqual` —
  `services/api/src/utils/media-access.ts:214-225`.
- Captcha bypass: dev/test only; production throws without `ALTCHA_HMAC_KEY` —
  `services/api/src/utils/altcha.ts:21-22,49`.
- Tracked `.env` files contain only `PUBLIC_*` SvelteKit keys (public by definition); no
  credentials in git. `apps/web/.env` sets captcha-skip for dev; `.env.production` does not.
- `docs/prototypes/` (≈90 MB of screenshots) is gitignored and never committed.
- Socket handshake authentication: verified —
  `services/api/src/realtime/socket.ts:225-240` (JWT + active-session check).
- Splitting the god files (`services/api/src/utils/messages.ts` 1087 lines,
  `src/realtime/socket.ts` 810, `routes/admin.ts` 775, `apps/web/src/lib/components/MessageBubble.svelte`
  1294, `apps/web/src/routes/admin/+page.svelte` 1243): real debt, deferred deliberately.
  Needs characterisation tests first, and a primary-agent design brief. Not a release blocker.
- Refresh-token migration out of `localStorage`: noted, not planned. Needs a design
  decision (cookie session vs. keeping `localStorage`) that belongs to the primary agent.
