# Tech Consultation Services

## Service 1: Tech Translator Call (Launch Month 2)
**Price:** $100
**Format:** 60-min remote consultation
**Target:** Pre-purchase confusion

**Deliverable:**
- 1-hour video/phone consultation
- 1-page PDF with:
  - Recommended specs for use case
  - 3 product options (low/mid/high budget)
  - Where to buy (affiliate links optional)
  - Basic setup tips

**Time Protection:**
- Strict 60-min timer
- No follow-up calls included
- PDF template reused (create once)

**Why $100:** Geek Squad charges $100-150, Best Buy memberships are $200/year. You're the affordable expert.

## Service 2: Custom PC Parts List (Launch Month 3)
**Price:** $175
**Format:** Async deliverable

**Deliverable:**
- PCPartPicker list with exact models
- Price tracking links
- Compatibility notes
- Step-by-step build guide PDF
- 30-min follow-up call

**Time Protection:**
- Async work (fits around schedule)
- 3-5 business day delivery
- Scheduled follow-up (not on-demand)

**Boundary:** Clear disclaimer - NOT liable if client breaks components during assembly.

## Service 3: New PC Setup & Optimization (Launch NOW)
**Price:** $175 flat rate
**Format:** In-person, 2-hour max
**Target:** Just-purchased computers, overwhelmed users

**Deliverable:**
- Windows/Mac initial configuration
- Driver installation + updates
- Remove bloatware
- Install essential software
- Security setup (antivirus, browser)
- 15-min usage tutorial

**Time Protection:**
- 2-hour hard limit
- Pre-scheduled with prayer time buffers
- Travel: 15 miles max from [zip code]
- Client must have PC unboxed + powered on before arrival

**Why This First:** Highest urgency, fastest conversion (people need help NOW).

## What You DON'T Do
❌ Ongoing tech support ("call anytime")
❌ Data recovery
❌ Virus/malware removal
❌ Hardware repair/diagnosis
❌ Home networking (until 20+ clients)
❌ Software piracy requests
❌ Free "quick questions" (scope creep killer)

**Someday Services** (after 20+ clients):
- Monthly optimization subscription ($50/mo)
- Small business IT packages
- Home network setup
